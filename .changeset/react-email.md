New package: React Email as an `EmailTemplate` renderer. `template` builds a core `EmailTemplate` from a React Email component, with typed data, per-locale messages, `lang` / `dir` / `<title>` filled in from the negotiated locale and subject, and a plain-text part that is derived, rendered by React Email or written alongside.
